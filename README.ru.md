# Valheim Admin

*[English version](README.md)*

Веб-панель для **выделенных серверов Valheim** с **публичной картой мира** для ваших игроков. Стандартный сервер — это окно консоли без админ-команд, без внятного лога событий и без удалённого управления. Valheim Admin добавляет всё это и работает с модами.

- **Карта мира для всех, без входа:** карта вашего мира открывается первой, с игроками, метками и, по желанию, порталами и местами. Можно показывать только исследованное. Работает с ключом мира `nomap`: администратор всегда видит всю карту.
- **Живая консоль:** лог сервера с фильтрами и поиском, и командная строка.
  - **Любая команда консоли игры** выполняется на сервере: ванильные (`listkeys`, `skiptime`, `event`, …) и команды других модов.
  - Команды панели: кик, бан, объявления, выдача предметов, глобальные ключи, набеги, пропуск ночи и другое.
  - **Команды на машине игрока:** `@Игрок god`, `@Игрок spawn Wood 50`, любая другая консольная команда. Прежде чем чит пометит персонажа, панель спросит подтверждение.
- **Журнал событий:** входы и выходы, смерти с причиной и убийцей, чат, победы над боссами, набеги, сохранения мира, падения, восстановления, изменения конфигов. Всё хранится, по журналу можно искать.
- **Игроки:** кто онлайн (пинг, позиция, версия мода), история сессий, наигранное время, смерти. Редактирование админов, банов и белого списка.
- **Слепки персонажей, совместимые с любыми модами:** при каждом сохранении мира сохраняются инвентарь, экипировка и навыки каждого игрока онлайн, со всем, что моды хранят на предметах (зачарования Epic Loot, камни Jewelcrafting, содержимое рюкзаков Adventure Backpacks, предметы модов Therzie, …), и с навыками модов. Слепки можно просматривать, сравнивать с тем, что у персонажа сейчас, и **восстанавливать** пропавшие предметы и навыки. У предметов настоящие игровые иконки и подсказки.
- **Конфиги и плагины:** правка файлов `BepInEx/config` в браузере (предыдущая версия сохраняется) и список плагинов, загруженных сервером.
- **Управление сервером** (с агентом): запуск, мягкая остановка, перезапуск, вахта после падений и зависаний, плановые рестарты с обратным отсчётом в игре, обновление через SteamCMD с предварительным бэкапом.
- Интерфейс на **английском и русском**.

## Два способа запуска

| | **Режим с агентом** — свой компьютер с Windows | **Автономный режим** — арендованный хостинг (G-Portal, Nitrado, …) или Linux |
|---|---|---|
| Что ставить | мод + агент (`ValheimAdmin.Agent.exe`) | только мод |
| Кто отдаёт панель | агент, в том числе пока сервер выключен | мод, прямо из игры |
| Запуск / остановка / вахта / плановые рестарты / обновление через SteamCMD | да | нет — через панель хостинга |
| Карта, консоль, события, игроки, слепки, конфиги | да | да |
| Где хранятся данные | SQLite в папке `data` агента | файлы в `BepInEx/config/ValheimAdmin` |

Режим мод выбирает сам: если сервер запущен агентом, панель отдаёт агент, иначе — мод.

```
Режим с агентом                                        Автономный режим

браузер ──HTTP──▶ ValheimAdmin.Agent.exe               браузер ──HTTP──▶ valheim_server + ValheimAdmin.dll
                    │ запускает сервер и следит за ним                        │
                    │ TCP 127.0.0.1 + секрет                                  │ RPC Valheim
                    ▼                                                         ▼
               valheim_server + ValheimAdmin.dll                     игры игроков с модом (необязательно)
                    │ RPC Valheim
                    ▼
               игры игроков с модом (необязательно)
```

**Тот же мод можно поставить игрокам** (один пакет Thunderstore для всех). Valheim хранит инвентарь и навыки на компьютере игрока, а не на сервере, поэтому снять слепок или вернуть предметы может только игра самого игрока, и иконки для панели тоже рисует игра игрока. Игроки без мода играют как обычно, просто без слепков.

## Установка — режим с агентом (свой сервер на Windows)

Нужно: Windows 10/11 или Windows Server с выделенным сервером Valheim (приложение Steam 896660) и [BepInEx для Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/). Агент самодостаточный, .NET ставить не нужно. По желанию: Tailscale для удалённого доступа, SteamCMD для обновлений.

1. Скачайте `ValheimAdmin-<версия>-win-x64.zip` из релизов и распакуйте, например, в `C:\ValheimAdmin`.
2. Скопируйте `mod\ValheimAdmin.dll` в папку `BepInEx\plugins` сервера (или поставьте мод через r2modman).
3. Если сервер запускался через `start_headless_server.bat`, остановите его: теперь его запускает агент.
4. Один раз запустите `agent\ValheimAdmin.Agent.exe`. Он создаст `agent\agent.json` и выведет **случайный пароль панели**. Закройте агент (Ctrl+C).
5. Отредактируйте `agent.json`. Обратные слэши в путях нужно удваивать (`C:\\Games\\Valheim`) или писать `/`.
   - `ServerDir`: папка с `valheim_server.exe`.
   - `Server`: имя, мир, пароль, порт и т. д., те же значения, что были в .bat-файле.
   - `Server.SaveDir`: оставьте пустым для стандартной `%USERPROFILE%\AppData\LocalLow\IronGate\Valheim` или укажите свою папку сохранений.
   - `PanelPassword`: здесь можно задать свой пароль. При следующем запуске агент заменит его хэшем.
   - `AutoStart`: поставьте `true`, когда всё настроено. Новый `agent.json` создаётся с `false`, чтобы сервер не запустился с шаблонными настройками.
6. Снова запустите агент и откройте `http://127.0.0.1:8095` на сервере или `http://<tailscale-ip>:8095` со своего ПК. Откроется карта; **Вход для админа** — внизу меню.

### Как открыть карту игрокам

По умолчанию агент слушает только `127.0.0.1` и адрес Tailscale. Чтобы карта была доступна игрокам:

- добавьте в `BindAddresses` адрес машины в локальной сети или публичный (или `0.0.0.0` — все интерфейсы), откройте TCP 8095 в брандмауэре Windows и, для доступа из интернета, пробросьте порт на роутере;
- игроки открывают `http://<ваш-адрес>:8095`. Публична только карта: всё остальное требует пароль администратора, а при включённом `[Map] PublicFog` неисследованные области вообще не покидают сервер.

Вход администратора работает откуда угодно. По обычному HTTP пароль идёт незашифрованным, поэтому для доступа из интернета включите HTTPS (`Https` в `agent.json`, сертификат PFX) или поставьте панель за обратный прокси с TLS. Через Tailscale трафик уже зашифрован.

### Удалённый доступ через Tailscale

При `"ListenTailscale": true` (по умолчанию) агент дополнительно слушает Tailscale-адрес машины (100.x.y.z). Откройте порт в брандмауэре Windows только для адресов Tailscale:

```powershell
New-NetFirewallRule -DisplayName "Valheim Admin panel" -Direction Inbound -Protocol TCP -LocalPort 8095 -RemoteAddress 100.64.0.0/10 -Action Allow
```

### Запуск как службы Windows

Запускайте службу **под своей учётной записью Windows**, которой принадлежат сохранения Valheim, а не под LocalSystem. В PowerShell от администратора:

```powershell
sc.exe create ValheimAdmin binPath= "C:\ValheimAdmin\agent\ValheimAdmin.Agent.exe" start= delayed-auto obj= ".\ВашПользователь" password= "ВашПарольWindows"
sc.exe start ValheimAdmin
```

При `"AutoStart": true` агент запускает игровой сервер вместе со службой. Удалить службу: `sc.exe stop ValheimAdmin`, затем `sc.exe delete ValheimAdmin`.

## Установка — автономный режим (хостинг, Linux)

1. Поставьте **Valheim Admin** из Thunderstore на сервер (через менеджер модов хостинга или r2modman) или загрузите `ValheimAdmin.dll` в `BepInEx/plugins`.
2. Один раз запустите сервер. Мод создаст `BepInEx/config/neocor.ValheimAdmin.cfg` и запишет в лог BepInEx строку **«Web panel admin password: …»**. Чтобы задать свой пароль, впишите его в `[Web] AdminPassword`: при следующем запуске или входе он заменится хэшем.
3. Панель слушает TCP-порт **8095** (`[Web] Port`). Хостинг должен пропускать входящие соединения на этот порт; у многих хостингов порт можно добавить в панели управления. Откройте `http://<адрес-сервера>:8095`.

Данные (журнал событий, слепки, иконки) хранятся в `BepInEx/config/ValheimAdmin`. Запуск, остановка и рестарты сервера остаются в панели хостинга.

## Игроки

Игроки ставят `ValheimAdmin` из Thunderstore / r2modman или кладут `ValheimAdmin.dll` в свой `BepInEx\plugins`. Это необязательно: без мода у игрока нет слепков, и консольные команды на его игре не выполнить. Удалённые команды и восстановление игрок может отключить в `BepInEx\config\neocor.ValheimAdmin.cfg` (`[Client] AllowServerCommands`, `AllowRestore`). На публичной карте игрок виден, только пока в игре у него включено «Видимость на карте» (`[Map] PublicPlayers`).

## Карта мира

- Рисуется на сервере по генератору мира, так же как игра рисует свою миникарту, поэтому моды генерации мира (Expand World, Better Continents, …) отражаются как есть. Первая отрисовка занимает минуту-две и кэшируется; кнопка **Перерисовать карту** в режиме администратора рисует её заново после смены таких модов.
- Исследованные области отслеживаются на сервере по тому, где бывали игроки. При `[Map] PublicFog` (включено по умолчанию) публичная карта показывает только их; полная карта не покидает сервер.
- Администратор видит всё: всех игроков (и скрытых), порталы с подписями, значки мест (боссы, торговцы, старт), надгробия, и может ставить метки (правый клик); метки можно сделать публичными.

## Слепки персонажей

- **Когда:** при каждом сохранении мира (автосохранение, команда `save`, выключение); по кнопке в панели; автоматически прямо перед любым восстановлением.
- **Что:** каждый предмет инвентаря: prefab, количество, качество, прочность, вариант, создатель, слот, надет ли он, **все пользовательские данные предмета** и сохранённая форма предмета самой игры; инвентари, которые моды добавляют игроку (доп. слоты экипировки или быстрые слоты); уровни навыков, в том числе навыков модов; пользовательские данные игрока (для справки). Панель показывает игровую иконку и подсказку каждого предмета вместе со строками модов.
- **Хранение:** одинаковые слепки хранятся один раз. По умолчанию хранится всё за последние 3 дня, затем по одному слепку в день до 60 дней. Самый свежий слепок персонажа не удаляется никогда.
- **Восстановление** (игрок должен быть онлайн и с модом):
  1. Выберите слепок. **Сравнить с текущим** отметит, чего у персонажа сейчас не хватает: зачарованный меч отличается от обычного того же типа (пунктирная рамка — у персонажа есть похожий предмет с другими данными), а стеки сравниваются по общему количеству.
  2. Выберите **Добавить выбранные предметы** или **Заменить инвентарь целиком**. Навыки можно не трогать, поднять до уровней слепка или выставить точно как в слепке.
  3. До любых изменений текущее состояние сохраняется слепком «перед восстановлением». Предметы собираются так же, как игра загружает сохранённого персонажа, поэтому моды, которые вмешиваются в загрузку предметов, видят обычную загрузку. Что не влезло, падает на землю у ног игрока. Предметы и навыки модов, которых больше нет, не восстанавливаются, а попадают в отчёт.
- Если какой-то мод меняет данные предмета во время обычной игры и «Сравнить» упорно считает такие предметы пропавшими, перечислите эти ключи в **Обслуживание → Ключи данных предметов, которые Сравнение не учитывает** (агент) или в `[Web] IgnoreDataKeys` (автономный режим).

## Команды консоли

| Команда | Действие |
|---|---|
| любая команда игры, например `listkeys`, `skiptime 3600`, `event army_eikthyr`, команды других модов | выполняется в консоли игры **на сервере**, вывод показывается. `help` покажет, что есть на сервере |
| `/<команда>` | всегда команда игры, даже если у панели есть команда с тем же именем (`/kick`, `/event`) |
| `players`, `status`, `plugins` | игроки онлайн, состояние сервера, загруженные плагины |
| `save` | сохранить мир (и снять слепки) |
| `say <текст>` | сообщение по центру экрана и в чат |
| `kick <игрок>`, `ban <игрок\|id>`, `unban <id>` | модерация |
| `admins`, `bans`, `permits`, `admin add\|remove <id>`, `permit add\|remove <id>` | админы, баны, белый список |
| `give <игрок> <prefab> [кол-во] [качество]` | выдать предметы (у ног, если у игрока нет мода) |
| `keys`, `setkey <ключ>`, `removekey <ключ>` | глобальные ключи (прогресс боссов, модификаторы мира) |
| `sleep` | промотать до утра |
| `events`, `event <имя> <игрок>`, `stopevent` | набеги |
| `snapshot [игрок]` | снять слепки сейчас |
| `@Игрок <консольная команда>` | выполняется на машине игрока, например `@Ragnar god`, `@Ragnar raiseskill Swords 10`, `@Ragnar spawn Wood 50`. Команды, которые может выполнить только сервер, выполняются на сервере |

Имена с пробелами берите в кавычки: `@"Big Olaf" heal`. Valheim выполняет чит-команды только для персонажей с пометкой об использовании читов; пометка остаётся навсегда (достижения), поэтому панель спрашивает, прежде чем её поставить.

## Настройки мода (`BepInEx/config/neocor.ValheimAdmin.cfg`)

| Раздел / ключ | По умолчанию | Значение |
|---|---|---|
| `[Map] Enabled` | `true` | рисовать карту мира на сервере |
| `[Map] TextureSize`, `PixelSize` | `2048`, `12` | разрешение карты; для миров, увеличенных модами, поднимите `TextureSize` |
| `[Map] DrawInBackground` | `true` | рисовать в фоновом потоке (выключите, если мод генерации мира ведёт себя странно) |
| `[Map] PublicFog` | `true` | публичная карта показывает только исследованное |
| `[Map] PublicPlayers` | `respect` | `respect` (только игроки с «Видимость на карте»), `all`, `none` |
| `[Map] PublicPortals`, `PublicLocations` | `false` | показывать порталы / значки мест на публичной карте (только в исследованных областях) |
| `[Web] Enabled` | `true` | автономный режим, когда агента нет |
| `[Web] Port`, `Bind` | `8095`, `*` | где слушает автономная панель |
| `[Web] AdminPassword` / `AdminPasswordHash` | — | новый пароль пишется в `AdminPassword`, он хэшируется |
| `[Web] Language` | `en` | язык журнала событий в автономном режиме |
| `[Web] DataDir`, `SnapshotKeepAllDays`, `SnapshotKeepDailyDays`, `IgnoreDataKeys` | | хранение и слепки в автономном режиме |
| `[Client] AllowServerCommands`, `AllowRestore` | `true` | игрок может запретить удалённые команды или восстановление |
| `[Server] AgentPort`, `AgentSecretFile` | — | только для сервера, запущенного без агента, но который должен с ним связаться |

## Параметры `agent.json`

| Ключ | По умолчанию | Значение |
|---|---|---|
| `Language` | `en` | `en` или `ru`: тексты событий, строки лога агента, объявления в игре |
| `HttpPort` | `8095` | порт панели |
| `BindAddresses` | `["127.0.0.1"]` | дополнительные адреса для прослушивания (`0.0.0.0` — все) |
| `ListenTailscale` | `true` | слушать также адрес Tailscale |
| `Https` | выкл. | `Port`, `CertificatePath` (PFX), `CertificatePassword` |
| `PanelPassword` / `PanelPasswordHash` | — | новый пароль пишется в `PanelPassword`, при запуске он хэшируется |
| `BridgePort` | `27961` | локальный порт между агентом и модом (только 127.0.0.1) |
| `ServerDir` | — | папка с `valheim_server.exe` |
| `Server.*` | — | `Name`, `Port`, `World`, `Password`, `Public`, `Crossplay`, `SaveDir`, `SaveInterval`, `Backups`, `BackupShort`, `BackupLong`, `ExtraArgs` (например, `-modifier raids none`) |
| `AutoStart` | `false` в новом файле | запускать сервер вместе с агентом |
| `Watchdog` | вкл., 180 с, 4/ч | `Enabled`, `HangSeconds`, `MaxRestartsPerHour` |
| `Restarts` | выкл. | `Enabled`, `Times` (`["06:00"]`), `WarnMinutes` (`[15,5,1]`) |
| `Snapshots` | 3 / 60 | `KeepAllDays`, `KeepDailyDays`, `IgnoreDataKeys` |
| `SteamCmdPath` | пусто | путь к `steamcmd.exe`, включает обновления |
| `DataDir` | `data` | база, архив логов, бэкапы |

Большинство параметров меняется и в панели, на вкладке **Обслуживание**. Сбросить пароль из командной строки: `ValheimAdmin.Agent.exe --set-password <новый>`.

## Папка данных (агент)

```
data\valheim-admin.db       события, сессии, слепки, иконки предметов, журнал действий (SQLite)
data\logs\server-*.log      архив лога сервера по дням
data\logs\stdout-latest.log сырой вывод текущего процесса сервера
data\config-backups\        прежние версии отредактированных конфигов
data\backups\               архивы мира и конфигов перед обновлениями
data\bridge.secret          общий секрет агента и мода
data\keys\                  ключи cookie входа (защищены DPAPI)
```

Картинку карты и исследованные области мод хранит в `BepInEx\config\ValheimAdmin\map\`.

## Решение проблем

- **В игре в «Избранном» / «Недавнем» у сервера красный крестик, но зайти можно.** Выключен `Server.Public`. С `-public 0` Valheim не отвечает на запросы статуса Steam. Включите **Публичный** на вкладке «Обслуживание» (или `"Public": true`) и перезапустите сервер.
- **Панель пишет «мод не подключён».** Проверьте, что `ValheimAdmin.dll` лежит в `BepInEx\plugins` сервера и что сам BepInEx загружается (`BepInEx\LogOutput.log`).
- **«Версии не совпадают».** У агента и мода общий протокол; обновляйте их вместе.
- **«Из той же папки запущена вторая копия сервера».** Что-то (`.bat`, другая утилита, старый агент) запустило `valheim_server.exe` рядом с управляемым. **Остановить** или **Убить процесс** завершают все копии из папки сервера; затем нажмите **Запустить**.
- **Карта пишет, что сервер выключен / карта готовится.** Карта рисуется после загрузки мира; первый раз это занимает минуту-две.
- **Автономный режим: панель не открывается.** Уточните у хостинга порт (он должен принимать TCP на `[Web] Port`) и поищите в логе BepInEx строку «Web panel (standalone mode) listening».
- **Агент не запускается и ругается на JSON.** В пути в `agent.json` одиночные обратные слэши: удвойте их или замените на `/`.

## Безопасность

- Один пароль администратора: хэш PBKDF2, сессии на cookie (HttpOnly, SameSite=Strict), блокировка после 5 неверных попыток и ограничение частоты входа.
- Публичная часть только для чтения: картинка карты (с туманом при `PublicFog`), видимые игроки и публичные метки. Всё остальное требует пароль.
- Агент слушает только 127.0.0.1 и адрес Tailscale, если вы не добавите другие. Открывая панель в интернет, включите HTTPS.
- Каждое действие из панели пишется в журнал с IP-адресом.
- Мод принимает подключение агента только с 127.0.0.1 и с секретом. На машинах игроков он принимает запросы только от сервера, к которому игрок подключён.

## Сборка из исходников

Нужен .NET 10 SDK (или новее) и установленный Valheim с BepInEx для ссылочных сборок.

```powershell
powershell -ExecutionPolicy Bypass -File package.ps1 -ValheimPath "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
```

Скрипт прогоняет тесты, собирает мод, публикует самодостаточный агент и кладёт оба архива в `dist\`. Для разработки: `dotnet run --project ValheimAdmin.Agent -- --config <путь к agent.json>`. Заметки для разработчиков и ИИ-агентов: [CLAUDE.md](CLAUDE.md).

## Ограничения

- Агент работает только под Windows; на других системах используйте автономный режим.
- Слепкам и восстановлению нужен мод у игрока, а для восстановления игрок должен быть онлайн. Иконки предметов появятся, когда онлайн побывает игрок с модом.
- Предметы модов, которые хранят состояние вне самого предмета (ни в его пользовательских данных, ни в сохранённой форме), могут вернуться не полностью.
- Большинство модов читают конфиг только при запуске, поэтому правки конфигов требуют рестарта сервера.
