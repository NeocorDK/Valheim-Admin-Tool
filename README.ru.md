# Valheim Admin

*[English version](README.md)*

Веб-панель для **выделенного сервера Valheim** на Windows. Стандартный сервер — это окно консоли без админ-команд, без внятного лога событий и без удалённого управления. Valheim Admin добавляет всё это. Панель открывается в браузере с любого устройства в вашей сети или через **Tailscale**.

- **Управление сервером:** запуск, мягкая остановка, перезапуск, сохранение, принудительное завершение. Если сервер уже запущен, агент подхватит его при старте.
- **Вахта:** перезапускает сервер после падения или зависания, с нарастающей паузой и ограничением числа перезапусков в час.
- **Плановые рестарты** с обратным отсчётом в игре, плюс разовый «рестарт через N минут».
- **Живая консоль:** лог сервера с фильтрами и поиском, и командная строка.
  - Серверные команды: кик, бан, объявления, выдача предметов, глобальные ключи, набеги, пропуск ночи и другое.
  - **Чит- и консольные команды на машине игрока:** `@Игрок god`, `@Игрок spawn …`, …
- **Журнал событий:** входы и выходы, смерти с причиной и убийцей, чат, победы над боссами, набеги, сохранения мира, падения, восстановления, изменения конфигов. Всё хранится, по журналу можно искать.
- **Игроки:** кто онлайн (пинг, позиция, версия мода), история сессий, наигранное время, смерти. Редактирование админов, банов и белого списка.
- **Слепки персонажей:** при каждом сохранении мира сохраняются инвентарь, экипировка и навыки каждого игрока онлайн, **включая зачарования Epic Loot и содержимое рюкзаков Adventure Backpacks**. Старые слепки можно просматривать, сравнивать с тем, что у персонажа сейчас, и **восстанавливать** пропавшие предметы и навыки.
- **Конфиги и плагины:** правка файлов `BepInEx/config` в браузере (предыдущая версия сохраняется) и список плагинов, загруженных сервером.
- **Обновления:** обновление сервера через SteamCMD с предварительным бэкапом мира и конфигов.
- Интерфейс на **английском и русском**.

## Как это устроено

```
Ваш ПК: браузер
    |
    |  HTTP + WebSocket через Tailscale или локальную сеть
    v
Агент: ValheimAdmin.Agent.exe, служба Windows на машине сервера
    |
    |  запускает процесс и следит за ним; говорит с модом по TCP 127.0.0.1 с секретом
    v
valheim_server.exe с ValheimAdmin.dll, загруженным через BepInEx
    |
    |  сетевые RPC Valheim
    v
Игры игроков с ValheimAdmin.dll (необязательно)
```

- **Агент** (`ValheimAdmin.Agent.exe`) — отдельная программа рядом с сервером. Он продолжает работать, когда сервер выключен или упал, и может запустить его снова. Агент отдаёт панель, хранит логи, события и слепки в SQLite и управляет процессом сервера.
- **Мод** (`ValheimAdmin.dll`, BepInEx) работает внутри сервера и выполняет команды агента.
- **Тот же мод можно поставить игрокам.** Valheim хранит инвентарь и навыки на компьютере игрока, а не на сервере, поэтому снять слепок или вернуть предметы может только игра самого игрока. Игроки без мода играют как обычно, просто без слепков.

## Требования

- Windows 10/11 или Windows Server с выделенным сервером Valheim (приложение Steam 896660).
- [BepInEx для Valheim](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/), установленный на сервер.
- Больше ничего: агент самодостаточный, .NET ставить не нужно.
- По желанию: Tailscale для удалённого доступа, SteamCMD для обновлений.

## Установка

1. Скачайте `ValheimAdmin-<версия>-win-x64.zip` из релизов и распакуйте, например, в `C:\ValheimAdmin`.
2. Скопируйте `mod\ValheimAdmin.dll` в папку `BepInEx\plugins` сервера.
3. Если сервер запускался через `start_headless_server.bat`, остановите его: теперь его запускает агент.
4. Один раз запустите `agent\ValheimAdmin.Agent.exe`. Он создаст `agent\agent.json` и выведет **случайный пароль панели**. Закройте агент (Ctrl+C).
5. Отредактируйте `agent.json`. Обратные слэши в путях нужно удваивать (`C:\\Games\\Valheim`) или писать `/`.
   - `ServerDir`: папка с `valheim_server.exe`.
   - `Server`: имя, мир, пароль, порт и т. д., те же значения, что были в .bat-файле.
   - `Server.SaveDir`: оставьте пустым для стандартной `%USERPROFILE%\AppData\LocalLow\IronGate\Valheim` или укажите свою папку сохранений.
   - `PanelPassword`: здесь можно задать свой пароль. При следующем запуске агент заменит его хэшем.
   - `AutoStart`: поставьте `true`, когда всё настроено. Новый `agent.json` создаётся с `false`, чтобы сервер не запустился с шаблонными настройками.
6. Снова запустите агент и откройте `http://127.0.0.1:8095` на сервере или `http://<tailscale-ip>:8095` со своего ПК.

### Удалённый доступ через Tailscale

При `"ListenTailscale": true` (по умолчанию) агент дополнительно слушает Tailscale-адрес машины (100.x.y.z). Используются только адрес Tailscale и `127.0.0.1`, публичный IP — никогда. Откройте порт в брандмауэре Windows только для адресов Tailscale:

```powershell
New-NetFirewallRule -DisplayName "Valheim Admin panel" -Direction Inbound -Protocol TCP -LocalPort 8095 -RemoteAddress 100.64.0.0/10 -Action Allow
```

Чтобы использовать адрес в локальной сети, добавьте его в `BindAddresses`. `0.0.0.0` означает все интерфейсы; открывайте так только в доверенной сети.

### Запуск как службы Windows

Запускайте службу **под своей учётной записью Windows**, которой принадлежат сохранения Valheim, а не под LocalSystem. В PowerShell от администратора:

```powershell
sc.exe create ValheimAdmin binPath= "C:\ValheimAdmin\agent\ValheimAdmin.Agent.exe" start= delayed-auto obj= ".\ВашПользователь" password= "ВашПарольWindows"
sc.exe start ValheimAdmin
```

При `"AutoStart": true` агент запускает игровой сервер вместе со службой. Удалить службу: `sc.exe stop ValheimAdmin`, затем `sc.exe delete ValheimAdmin`.

### Игроки

Игроки ставят `ValheimAdmin` из Thunderstore / r2modman или кладут `ValheimAdmin.dll` в свой `BepInEx\plugins`. Это необязательно: без мода у игрока нет слепков, и консольные команды на его игре не выполнить. Удалённые команды и восстановление игрок может отключить в `BepInEx\config\neocor.ValheimAdmin.cfg`.

## Слепки персонажей

- **Когда:**
  - при каждом сохранении мира (автосохранение, команда `save`, выключение);
  - по кнопке в панели;
  - автоматически прямо перед любым восстановлением.
- **Что:** каждый предмет инвентаря: prefab, количество, качество, прочность, вариант, создатель, слот, надет ли он, и **все пользовательские данные предмета**. В них Epic Loot хранит зачарования, а Adventure Backpacks — содержимое рюкзака, поэтому восстановление работает без API этих модов. Уровни навыков тоже сохраняются. Панель показывает игровой тултип каждого предмета вместе со строками Epic Loot.
- **Хранение:** одинаковые слепки хранятся один раз.
  - По умолчанию хранится всё за последние 3 дня, затем по одному слепку в день до 60 дней. Самый свежий слепок персонажа не удаляется никогда.
- **Восстановление** (игрок должен быть онлайн и с модом):
  1. Выберите слепок. **Сравнить с текущим** отметит, чего у персонажа сейчас не хватает: зачарованный меч отличается от обычного того же типа, а стеки сравниваются по общему количеству.
  2. Выберите **Добавить выбранные предметы** или **Заменить инвентарь целиком**. Навыки можно не трогать, поднять до уровней слепка или выставить точно как в слепке.
  3. До любых изменений текущее состояние сохраняется слепком «перед восстановлением». Что не влезло, падает на землю у ног игрока.

## Команды консоли

| Команда | Действие |
|---|---|
| `players`, `status`, `plugins` | игроки онлайн, состояние сервера, загруженные плагины |
| `save` | сохранить мир (и снять слепки) |
| `say <текст>` | сообщение по центру экрана и в чат |
| `kick <игрок>`, `ban <игрок\|id>`, `unban <id>` | модерация |
| `admins`, `bans`, `permits`, `admin add\|remove <id>`, `permit add\|remove <id>` | админы, баны, белый список |
| `give <игрок> <prefab> [кол-во] [качество]` | выдать предметы (у ног, если у игрока нет мода) |
| `keys`, `setkey <ключ>`, `removekey <ключ>` | глобальные ключи (прогресс боссов, модификаторы мира) |
| `sleep` | промотать до утра |
| `events`, `event <имя> <игрок>`, `stopevent` | набеги |
| `snapshot [игрок]` | снять слепки сейчас |
| `@Игрок <консольная команда>` | выполнить любую консольную команду игры на машине игрока с включёнными читами, например `@Ragnar god`, `@Ragnar raiseskill Swords 10`, `@Ragnar spawn Wood 50` |

Имена с пробелами берите в кавычки: `@"Big Olaf" heal`.

## Параметры `agent.json`

| Ключ | По умолчанию | Значение |
|---|---|---|
| `Language` | `en` | `en` или `ru`: тексты событий, строки лога агента, объявления в игре |
| `HttpPort` | `8095` | порт панели |
| `BindAddresses` | `["127.0.0.1"]` | дополнительные адреса для прослушивания |
| `ListenTailscale` | `true` | слушать также адрес Tailscale |
| `PanelPassword` / `PanelPasswordHash` | — | новый пароль пишется в `PanelPassword`, при запуске он хэшируется |
| `BridgePort` | `27961` | локальный порт между агентом и модом (только 127.0.0.1) |
| `ServerDir` | — | папка с `valheim_server.exe` |
| `Server.*` | — | `Name`, `Port`, `World`, `Password`, `Public`, `Crossplay`, `SaveDir`, `SaveInterval`, `Backups`, `BackupShort`, `BackupLong`, `ExtraArgs` (например, `-modifier raids none`) |
| `AutoStart` | `false` в новом файле | запускать сервер вместе с агентом |
| `Watchdog` | вкл., 180 с, 4/ч | `Enabled`, `HangSeconds`, `MaxRestartsPerHour` |
| `Restarts` | выкл. | `Enabled`, `Times` (`["06:00"]`), `WarnMinutes` (`[15,5,1]`) |
| `Snapshots` | 3 / 60 | `KeepAllDays`, `KeepDailyDays` |
| `SteamCmdPath` | пусто | путь к `steamcmd.exe`, включает обновления |
| `DataDir` | `data` | база, архив логов, бэкапы |

Большинство параметров меняется и в панели, на вкладке **Обслуживание**. Сбросить пароль из командной строки: `ValheimAdmin.Agent.exe --set-password <новый>`.

## Папка данных

```
data\valheim-admin.db       события, сессии, слепки, журнал действий (SQLite)
data\logs\server-*.log      архив лога сервера по дням
data\logs\stdout-latest.log сырой вывод текущего процесса сервера
data\config-backups\        прежние версии отредактированных конфигов
data\backups\               архивы мира и конфигов перед обновлениями
data\bridge.secret          общий секрет агента и мода
data\keys\                  ключи cookie входа (защищены DPAPI)
```

## Решение проблем

- **В игре в «Избранном» / «Недавнем» у сервера красный крестик, но зайти можно.** Выключен `Server.Public`. С `-public 0` Valheim не отвечает на запросы статуса Steam. Включите **Публичный** на вкладке «Обслуживание» (или `"Public": true`) и перезапустите сервер. Без флага `-public` Valheim тоже считает сервер публичным.
- **Панель пишет «мод не подключён».** Проверьте, что `ValheimAdmin.dll` лежит в `BepInEx\plugins` сервера и что сам BepInEx загружается (`BepInEx\LogOutput.log`).
- **Обновляйте агент и мод вместе.** У них общий протокол: новый мод не свяжется со старым агентом.
- **«Из той же папки запущена вторая копия сервера».** Что-то (`.bat`, другая утилита, старый агент) запустило `valheim_server.exe` рядом с управляемым. Сам агент вторую копию не запускает и не отдаёт ей связь с панелью. **Остановить** или **Убить процесс** завершают все копии из папки сервера; затем нажмите **Запустить**.
- **Агент не запускается и ругается на JSON.** В пути в `agent.json` одиночные обратные слэши: удвойте их или замените на `/`.

## Безопасность

- Панель защищена одним паролем: хэш PBKDF2, сессии на cookie, блокировка после 5 неверных попыток.
- Агент слушает только 127.0.0.1 и адрес Tailscale, если вы не добавите другие.
- Каждое действие из панели пишется в журнал с IP-адресом.
- Мод принимает подключение агента только с 127.0.0.1 и с секретом. На машинах игроков он принимает запросы только от сервера, к которому игрок подключён.

## Сборка из исходников

Нужен .NET 10 SDK (или новее) и установленный Valheim с BepInEx для ссылочных сборок.

```powershell
powershell -ExecutionPolicy Bypass -File package.ps1 -ValheimPath "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
```

Скрипт прогоняет тесты, собирает мод, публикует самодостаточный агент и кладёт оба архива в `dist\`. Для разработки: `dotnet run --project ValheimAdmin.Agent -- --config <путь к agent.json>`.

## Ограничения

- Агент работает только под Windows.
- Слепкам и восстановлению нужен мод у игрока, а для восстановления игрок должен быть онлайн.
- Восстановление идёт через код инвентаря самого Valheim. Предметы модов, которые хранят данные вне пользовательских данных предмета, могут вернуться не полностью.
- Большинство модов читают конфиг только при запуске, поэтому правки конфигов требуют рестарта сервера.
